# Privacy Policy for LinkDeck

Effective Date: 24 November 2025

LinkDeck is a browser extension designed to help users save and organize their personal web links. We value your privacy and are committed to protecting your data.

## What Data We Collect
LinkDeck does NOT collect, transmit, or store any personal data.

The extension stores user-created links **locally on the user's own device** using Chrome's `storage` API. This data is NOT sent to us or any third party.

## How Data Is Used
The data stored locally is used solely to:

- Display the user's saved links
- Allow the user to add or delete their own links

We **do not** use this data for analytics, advertising, profiling, or sharing.

## Third-Party Sharing
We do NOT sell, share, or transfer any user data to third parties.

## Remote Code
LinkDeck does NOT execute any remote code or load external scripts.
